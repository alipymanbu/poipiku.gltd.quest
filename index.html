Poipiku 是什么

Poi 来自日语，意思是轻松地把东西抛出去——名字本身就说明了这个社区的态度：作品像随手抛出的一张纸，不必追求一步到位。它由日本的 Pipa.jp Ltd. 推出，主打低压力的分享氛围，在二次元画师圈子里人气很高。

和讲究「成稿」的平台不同，这里草稿、线稿、练习、废弃稿都是正当内容。发布时可以按完整度标记涂鸦、练习稿、成稿三类，读者会按这个预期来看你的图；单张插画、多张系列、长条漫画都能发。

互动也被刻意做轻了：读者主要用匿名表情回应作品，反馈不公开署名，压力比公开评论小得多。找图则靠标签与 ID 两条路——关键词、标签顺藤摸瓜，别人报一个 ID 就能直接定位到人。除了安卓客户端，Poipiku 也有网页版，账号互通，浏览和收藏跟着账号走。

03

玩法特点

六个让它显得不太一样的点。

草稿即内容

涂鸦、练习稿、画到一半的进度图随手就能发，「未完成」在这里不是减分项，而是日常。

匿名表情互动

用表情回应作品，反馈不署名，喜欢就「poi」一下，比写评论轻快得多。

公开范围随作品设

公开、仅限关注、密码访问、一键展开，逐张选择；想安静存图也有对应的组合。

标签 + ID 双检索

关键词、热门标签顺着一个题材多看几张；报 ID 直接定位到人，不受翻译差异影响。

长条漫画竖屏读

多图作品支持连续下翻，长条漫画不用一张张点开，通勤单手刷也顺手。

轻量不挑设备

客户端只有 6MB 出头，存储不用特意腾，滑动浏览在老一点的安卓机上也流畅。

谁能看到你的图：公开范围逐张选

发布时按作品逐张设置，上一张的设定不会带到下一张。

设置效果适合场景
公开任何人可见正常分享
仅限关注只有关注你的人可见只想给熟粉看的内容
密码访问输入你设的密码才能展开控制传播范围，密码自己发给想给的人
一键展开点一下才显示完整内容减少被随手划过、被机器抓取的概率

另有两个和曝光有关的选项：「预览垫子」（作品先以模糊预览出现，点开才见原图）与「避免被搜索引擎收录」。只想安安静静存图给少数人看的话，「密码访问 + 预览垫子」是比较稳妥的组合。

常见问题

没画完真的可以发吗？

可以。社区的习惯就是草稿、练习稿与成稿混在一条流里，发布时标记好完整度（涂鸦 / 练习稿 / 成稿），读者会按这个预期来看。

要腾很大的存储空间吗？

不用。客户端只有 6MB 出头，对存储几乎没要求；倒是发图、刷图会产生缓存，空间紧张时清一次应用缓存即可。

有些图点开是警告页或者要密码？

这是作者自己设的门槛，不是故障。分级警告类的作品，登录后完成一次年龄认证就能看；密码作品只能找作者本人要密码，要不到就只能看封面。

装好后界面不是中文怎么办？

这份安装包默认就是简体中文界面。万一看到的不是中文，在主界面右上角的设置里把语言切到「简体中文」，即时生效，不用重装。

从一张草稿开始

不用等「画好了再发」。装上客户端，今天那张没画完的图，也可以先抛出来。
